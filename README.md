# Rock Paper Scissors Game 🎮

A simple, interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features
* Live score tracking (Wins, Losses, Draws).
* Interactive UI with clickable choices.
* Reset button to clear scores.

## How to Play
1. Click on Rock, Paper, or Scissors.
2. The computer will make a random choice.
3. Your score will update automatically!
